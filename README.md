# covid-19-economic-impact-analysis
(A) COVID-19 Economic Impact Analysis

(B) Project Overview
This project shows how the COVID-19 pandemic affected global inflation and the United States economy using publicly available economic indicators. The analysis examines inflation and unemployment trends before (2017-2019), during (2020-2022), and after the pandemic (2023-2025) to identify how these key indicators changed over time.

(C) Objectives
1. Explore global inflation during the onset of the pandemic.
2. Explore global inflation during the onset of the pandemic.
3. Compare U.S. inflation before, during, and after COVID-19.
4. Compare U.S. unemployment across the same periods.
5. Build KPI summaries in Excel.
6. Communicate findings through visualizations.

(D) Tools: Microsoft Excel (Power Query, Pivot Tables, Pivot Charts, PowerPivot)

(E) Dataset Source: Kaggle

(F) Project Roadmap

Project Objectives → Data Collection → Data Cleaning → Exploratory Data Analysis → Visualizations → Key Findings → Limitations → Lessons Learned

(H) Limitations
- Approximately 40 countries had missing inflation data.
- The analysis focused primarily on inflation and unemployment.
- Missing observations may affect the interpretation of global trends.

(I) Lessons Learned
- Import and clean data using Power Query.
- Summarize data with Power Pivot and create KPI dashboards in Excel.
- Recognize and communicate data limitations.
